# FastQuiz — interactive FastAPI quiz

Full-stack learning MVP:
- React + Vite frontend
- FastAPI backend
- PostgreSQL on Render (via `DATABASE_URL`); SQLite fallback for local development
- Email/password registration and login
- Google sign-in (requires Google OAuth Web Client ID)
- Role-protected quiz authoring, scoring, and quiz history
- Assigned-task tracking, progress comments, notifications, activity history, and reports
- Authenticated practice voting, points, roses 🌹, and leaderboard

## Local backend
```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Create `backend/.env` from `.env.example` if it does not already exist. Replace the JWT placeholder with a private value generated by `openssl rand -hex 32`. The example uses local SQLite; set `DATABASE_URL` to your PostgreSQL URL only if using PostgreSQL. Set matching `GOOGLE_CLIENT_ID` only if Google sign-in is configured.

```bash
alembic upgrade head
uvicorn app.main:app --reload
```
API docs: http://127.0.0.1:8000/docs

### First Super Admin
1. Start the backend and register the account that should own the app.
2. Stop the server, then from `backend/` run:
   ```bash
   python -m app.bootstrap_super_admin owner@example.com
   ```
3. Restart the backend and sign out/in. This command only works when no active Super Admin exists. Never expose it as a public endpoint.

## Local frontend
```bash
cd frontend
cp .env.example .env # only if frontend/.env does not already exist
# Set VITE_API_URL to http://127.0.0.1:8000 and VITE_GOOGLE_CLIENT_ID if using Google login
npm install
npm run dev
```

See `DEPLOYMENT.md` for the Render + PostgreSQL + Vercel + Google OAuth steps.

## Tests
From `backend/`, install the test tools and run the isolated API suite:
```bash
pip install -r requirements-dev.txt
pytest -q
```
The tests use a temporary SQLite database and do not modify `backend/fastquiz.db`.

## Current limits
- Password reset and email verification require an email-delivery provider and are not enabled.
- Admins can create seven-day, single-use member invitation codes; they must share the code manually because outbound email is not configured.
- Super Admins can change account roles and activate/deactivate accounts; the last active Super Admin cannot be removed or deactivated.
- Notifications are in-app. Automated deadline reminders and outbound email notifications need a scheduler/email provider.
- Quiz attempts are single-submit per user and are scored by the backend; question changes are blocked after attempts exist.
